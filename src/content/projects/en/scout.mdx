SCOUT is a valuation service built on public methodology: Damodaran-style DCF and Monte Carlo simulation. It shows a stock's fair value as a range and a distribution instead of a single number. It is a solo project and has not launched yet.

The valuation engine is a pure Kotlin module with no Spring dependency. A Spring Boot API, a Flutter app, a React operations console and a Next.js web front sit on top of it. Model inputs change only after filing ingestion, a freshness check and an update proposal, and then only if the proposal passes an approval gate. The LLM advisor can submit proposals to that gate but cannot change values itself.

In the app, a margin-of-safety view shows whether a price is worth acting on, and a pause prompt steps in when the user is about to chase a stock.

2. **Stock report (PRO, simple mode).** Pick a scenario on a bear-to-bull ladder. ★ marks the recommended scenario and ◎ the one nearest the reference price. The margin-of-safety chips update the entry price instantly. Per-scenario values and theses are masked.
3. **Buy review.** When the price is above fair value, the app pauses the user with three self-check questions about urgency, paying above fair value and following others' pace. Figures masked.
